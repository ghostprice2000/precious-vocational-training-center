# Precious Vocational Training Center

Site vitrine bilingue (français/anglais) du Precious Vocational Training Center.

## Pages

- `index.html` : accueil
- `formations.html` : catalogue des formations
- `formation.html` : fiche détaillée, par exemple `formation.html?id=auxiliaire-vie`
- `centre.html` : mission, pédagogie, valeurs et campus
- `contact.html` : admissions et candidature

## Aperçu local

Depuis le dossier du projet, lancez un serveur statique, par exemple :

```powershell
python -m http.server 8000
```

Puis ouvrez `http://localhost:8000`.
